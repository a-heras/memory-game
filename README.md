# Memory Game

Игра «Найди пару» на чистом JavaScript, HTML и CSS. Без библиотек и фреймворков.
Интерфейс создаётся через `document.createElement`.

## Демо

🔗 **Онлайн-версия:** https://a-heras.github.io/memory-game/

## Как играть

- 16 карточек: 8 пар одинаковых эмодзи.
- Откройте две карточки: совпали — остаются открытыми, нет — закроются через секунду.
- Цель: найти все 8 пар за минимальное число ходов.
- Кнопка «Новая игра» перемешивает поле и обнуляет счётчики.
- Кнопка «Таблица лидеров» показывает до 10 лучших результатов (хранятся в `localStorage`).

## Локальный запуск

Скчать проект, запустить `index.html`.
